02 · Settled ground

Five things all four agree on

Four organisations with different incentives reach the same conclusions.

1

Code generation is no longer the constraint.The bottleneck moved to the work around the code: planning, review, maintenance.

2

Human review becomes the binding constraint.Anthropic, Atlassian and Shopify reach this independently. Google names it as a risk.

3

Context quality decides output quality.Not model choice. What the agent is told about your systems is the differentiator.

4

Humans stay accountable for judgement.Agents execute and enforce. People decide, approve and own.

5

It's an operating-model change, not a tool purchase.Explicit for Atlassian and Shopify, implied by Anthropic, not stated by Google.

When organisations competing for the same budget agree this precisely, the agreement is the finding.

04 · Where they part ways

Three real disagreements

Not differences in emphasis. Places where following one source means not following another.

1. Where does the source of truth live?

The repoThe context graph
Anthropic
Atlassian

Anthropic: markdown artifacts in git are authoritative; the commit history is the audit trail. Atlassian: one connected context layer across tools is authoritative, and the repo is one input.

An architecture decision, and expensive to reverse.

2. One standard tool, or many?

One governed surfaceMany tools
Anthropic + Atlassian
Shopify

Shopify: "we don't know yet what's gonna win." Centralise the plumbing, not the choice.

Governance appetite decides this, not engineering preference.

3. How hard are the limits?

Hard blocksGuidance only
Anthropic
Shopify
Google

Anthropic: hooks that block, settings engineers can't override. Shopify: iteration limits and spend alerts, deliberately no hard caps. Google: practices, no enforcement mechanism.

Regulated organisations will land near Anthropic. Know what it costs in developer friction.

07 · Not a winner

Four different contributions to one approach

From Anthropic
The artifact chain and the enforcement model

Every stage commits a file the next stage reads; the commit history is the audit trail. Skills advise, hooks block. The part that survives contact with auditors.

From Atlassian
The operating model and measurement discipline

Context is a platform investment, not a per-team effort. Measure before you scale, so you can tell real gains from hype.

From Google Cloud
The risk framing and the review policy

Security flaws in generated code, IP exposure, comprehension debt, and the rule that generated code gets no exemption from review.

From Shopify
The adoption mechanics

Nudge, showcase, make usage visible. Match the tool to the user. Protect comprehension as hard as you push adoption.
